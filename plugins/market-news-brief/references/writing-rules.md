# 措辞规范

报告分两个区：**事实区**（核心要点、新闻总结、自然灾害与突发事件）和**分析区**（市场分析）。两个区的规矩不同：事实区只陈述不评价，分析区可以判断，但每个判断都要有依据、有边界，而且不能变成投资建议。

## 一、事实区

### 每条新闻要回答什么

| 要素 | 示例 |
|------|------|
| 何时 | 10 月 7 日（美东时间） |
| 谁 | 美联储联邦公开市场委员会（FOMC） |
| 做了什么 | 宣布将联邦基金利率目标区间下调 25 个基点至 X%–Y% |
| 关键数字 | 投票 10:2；点阵图中值显示年内还将降息 1 次 |
| 各方表态 | 主席在发布会上表示“……”；两名反对票委员主张维持不变 |
| 来源 | 美联储声明；路透社报道 |

`summary` 用 1–3 句写清前四项，`keyPoints` 补充细节，`figures` 放最关键的 2–4 个数字。

### 六条规则

**1. 数字代替形容词。** 涨跌、规模、程度一律用数字表达。来源本身用了形容词，要么换成数字，要么作为引语加引号并归属。

**2. 观点必须归属。** 任何判断、预测、评价都要写明是谁说的：“国际货币基金组织预计……”“分析师普遍认为……（据彭博调查）”。没有出处的判断不写进事实区。

**3. 不补因果。** 来源没有明确说 A 导致 B，就不要写“受 A 影响，B……”，改写为“A 发生的同一天，B……”，或分开写两条。来源说了因果，就写“据 X 报道，B 主要受 A 影响”。

**4. 不下结论、不做延伸。** “这意味着”“标志着”“预示着”“说明了”这类解读挪到分析区。

**5. 争议事件各方并列。** 冲突、制裁、贸易摩擦中，各方的说法分别归属列出。篇幅大体对等，不用引号暗示某一方说法可疑，也不对任何一方使用带褒贬色彩的称谓。

**6. 区分已发生和计划中。** “宣布”“已实施”“拟”“计划于”“据知情人士”等用词要准确，未落地的政策不写成已生效。

### 情绪词替换表

| 不要写 | 改为 |
|--------|------|
| 暴跌 / 跳水 / 闪崩 / 血洗 | 下跌 X% / 盘中一度下跌 X% |
| 暴涨 / 狂飙 / 井喷 | 上涨 X% / 创 N 年来最大单日涨幅（附来源） |
| 大超预期 / 不及预期 | 高于 / 低于市场预期的 X%（据某某调查） |
| 重磅 / 炸裂 / 史诗级 / 历史性 | 删去，用事实本身说明分量（规模、范围、首次与否） |
| 利好 / 利空 / 好消息 / 坏消息 | 删去；对市场的潜在影响放到分析区 |
| 令人担忧 / 令人振奋 / 遗憾的是 | 删去，或归属给具体发言人：“某某表示担忧” |
| 显然 / 毫无疑问 / 必将 / 势必 | 删去 |
| 强硬 / 软弱 / 鹰派胜利 | 写具体措施和措辞变化；“鹰派/鸽派”只作为市场通行术语，并归属给“市场人士”等 |
| 终于 / 竟然 / 居然 | 删去 |

构建脚本会扫描事实区里的这类词并给出告警。命中的如果是引语原文，保留并确认引号和归属都在；否则改写。

### 正反例

> ❌ 美联储终于开启降息，美股应声暴涨，市场迎来重磅利好。
>
> ✅ 10 月 7 日，美联储宣布将联邦基金利率目标区间下调 25 个基点至 X%–Y%。当日标普 500 指数收涨 1.2%。（来源：美联储声明；路透社）

> ❌ 中国出台强力刺激措施，彰显稳增长决心，经济有望触底回升。
>
> ✅ 国务院常务会议审议通过某某措施，包括 A、B、C 三项。新华社报道称，相关措施旨在“……”（引语）。

> ❌ 俄罗斯经济在制裁下濒临崩溃，卢布崩盘。
>
> ✅ 窗口内卢布兑美元汇率下跌 X%（据俄罗斯央行官方汇率）。俄罗斯央行行长表示……；路透社援引某机构分析称……

### 核心要点

- 4–8 条，按重要性排列，每条一句话。
- 只写事实，规则与新闻条目相同。
- 每条挂上对应条目的引用（`refs`），读者点击可跳转到详情。
- 优先选 ★★★ 条目，并兼顾不同经济体。不要全是同一国家，除非用户只关心这一国。

## 二、分析区

### 判断的写法：证据 → 解读 → 边界

每个判断都按这个链条写：

1. **证据**：引用新闻条目或市场数据，用 `[[条目id]]` 标注。
2. **解读**：这些证据合起来反映了什么。用“显示”“反映”“指向”“与……一致”这类有分寸的动词。
3. **边界**：置信度（高/中/低）、反向证据、成立条件。

> ✅ 美国 9 月非农新增就业低于预期 [[us-nfp]]，同期初请失业金人数升至年内高位 [[us-claims]]，两项数据都指向劳动力市场降温，置信度中。反向证据：薪资增速仍高于 4%，服务业 PMI 维持扩张。
>
> ❌ 美国经济正在走向衰退，美联储必然加速降息。

### 置信度的含义

| 置信度 | 含义 |
|--------|------|
| 高 | 多项独立证据方向一致，反向证据弱 |
| 中 | 主要证据支持，但存在不可忽视的反向证据或数据有滞后 |
| 低 | 证据有限或彼此矛盾，属于需要后续数据验证的初步判断 |

### 不能写的内容

分析区的目标是描述局势，不是给方案。以下内容不要出现：

- 买入、卖出、增持、减持、持有某类资产或某个标的的建议
- 加仓、减仓、满仓、清仓、抄底、逃顶、追高等交易指令类词语
- 目标价、点位预测、收益率预测、仓位比例或资产配置比例
- “稳赚”“保本”“翻倍”“必涨”“必跌”等收益承诺或确定性断言
- 点名具体股票、基金、理财产品作为推荐

可以写：

- 当前环境对某类资产**历史上通常意味着哪些风险因素**（例如“利率上行阶段，长久期资产价格对利率变化更敏感”）
- 需要关注的指标、事件和触发条件
- 通用的风险管理思路（见下）

构建脚本会扫描分析区里的投资建议类措辞并给出告警。

### 风险规避思路的写法

用“适用情形 → 风险管理思路”的结构，情形必须来自本期分析识别出的具体环境特征：

> 适用情形：本周主要央行会议与重要数据密集，市场隐含波动率上升
>
> 思路：关注组合整体杠杆和单一资产集中度；预留流动性，以应对价格跳空和成交清淡；重大事件前后留意买卖价差扩大带来的交易成本。

> 适用情形：美元指数区间上涨 2%，多个新兴市场货币走弱
>
> 思路：梳理外币资产和负债的汇率敞口；了解可用的对冲方式及其成本；避免把汇率变动和资产本身的价格变动混为一谈。

收尾时提醒：思路是否适用，取决于读者自身的资金性质、期限和风险承受能力，必要时咨询持牌专业人士。模板的免责声明已包含这层意思，正文不必每条重复。

### 情景推演的写法

- 一般写三个情景：基准、上行、下行。名称也可以按实际议题命名，如“通胀黏性情景”。
- 每个情景写：描述、触发条件、观察指标。
- 可能性只用定性词（相对较高 / 中等 / 较低），不给百分比。
- 情景描述的是**环境如何演变**，不是“某资产会涨到多少”。
