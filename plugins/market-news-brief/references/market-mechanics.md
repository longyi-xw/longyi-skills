# 市场原理、三层思维与防御策略库

分析区要回答的不只是“发生了什么”，还有“为什么会这样”“然后会怎样”“市场在怎么应对”。本文件是这几件事的工具箱。

## 1. 三层思维：因果链怎么写

| 层次 | 回答的问题 | 停在这一层的后果 |
|------|-----------|-----------------|
| 第一层 · 表象 | 发生了什么？多数人的第一反应是什么？ | 只是复述新闻，读者学不到东西 |
| 第二层 · 机制 | 为什么会这样？价格被哪条传导链、哪个原理推动？和**预期**比差多少？ | 能解释过去，但不会推演 |
| 第三层 · 推演 | 然后呢？谁会被迫调整？共识已经定价了多少？二阶效应在哪？逻辑在什么条件下反转？ | —— |

### 写作要领

- **选题**：挑本期最反直觉或影响最大的 2–4 个现象，题目写成问句，例如“为什么 CPI、PPI 同步上行，多国股指反而下跌？”。反直觉的现象最能教会读者东西。
- **第一层**要写出“直觉答案”，第二层的纠偏才有落点。
- **第二层**落到传导链 `chain`：3–6 个节点，每个节点标 `observed`（本期已观察到，带引用）或 `inferred`（推断）。再点名一个市场原理（见第 2 节），用本期的真实数字讲，不要只贴定义。
- **第三层**至少包含三样东西：一个二阶效应（谁会被迫调整）、一个“已定价程度”的判断、一个反转条件（什么情况下这条链会松动）。
- **反向证据**：哪些事实与这条链不一致。
- **思考题**：读者能用后续数据自己验证的具体问题，不要写修辞问句。

### 完整示例

> **为什么 CPI、PPI 同步上行，多国股指反而下跌？**
>
> 现象：美国 CPI 同比高于预期 [[us-cpi]]，中国 PPI 降幅收窄 [[cn-ppi]]；同期标普 500 与恒生指数下跌，美债 10 年期收益率上行。
>
> **第一层 · 表象**：物价上涨，企业的名义收入也跟着涨，直觉上对股市不是坏事。
>
> **第二层 · 机制**：市场交易的是“意外”。CPI 高于预期 → 利率期货隐含的降息时点后移 → 美债收益率上行 → 估值公式的分母变大，越依赖远期现金流的资产（高估值成长股、长久期债券）跌得越多。同时，PPI 涨得比 CPI 快时，中下游企业成本涨得比售价快，利润率被挤压。估值和盈利预期一起下修，就是“戴维斯双杀”。
>
> **第三层 · 推演**：利率上行最先冲击长久期资产，资金通常向现金流近、定价权强的方向迁移。如果央行确实转向更紧，美元走强会把压力传导给新兴市场货币和资产。反转条件：通胀见顶的证据出现（PPI 环比转负、核心通胀连续放缓），此前对利率最敏感、跌得最多的资产通常最先修复。还要判断已定价程度：利率期货已经计入多少次加息，决定了下一次数据的“意外”空间还有多大。
>
> 原理：贴现率效应 + 成本推动型通胀的利润挤压。
>
> 反向证据：服务业 PMI 仍在扩张，企业盈利预期尚未明显下修。
>
> 思考题：如果下个月 PPI 回落、CPI 仍然偏高，这条链上哪一环会先松动？

## 2. 市场原理库

讲原理时用大白话加本期数字。下表是常用原理，不限于此。

| 原理 | 一句话 | 典型场景 | 常见误读 |
|------|--------|---------|---------|
| 贴现率效应 | 资产价格约等于未来现金流折现，利率上行会让远期现金流缩水；现金流越远（高估值成长、长债），对利率越敏感 | 通胀超预期、加息预期升温时，成长股与长债同跌 | 以为利率只影响银行和地产 |
| 预期差定价 | 价格反映的是相对预期的意外，不是数据本身的好坏 | “数据好市场跌”：强数据推迟了宽松预期；“买预期，卖事实” | 用同比、环比的好坏判断市场方向 |
| 盈利 × 估值 | 股价 = 每股盈利 × 估值倍数，两者同向时效果放大（戴维斯双击 / 双杀） | 成本冲击叠加利率上行 → 双杀；复苏初期 → 双击 | 只看盈利或只看估值 |
| 成本推动 vs 需求拉动 | 需求拉动的通胀伴随销量和利润扩张；成本推动的通胀挤压利润、压制需求 | PPI 涨得比 CPI 快：上游受益，中下游利润被挤压（PPI−CPI 剪刀差） | 把所有通胀都当成“经济过热” |
| 政策反应函数 | 市场交易的是央行“会怎么回应”。坏数据可能因宽松预期被市场欢迎，好数据反之 | “坏消息就是好消息” | 只看数据，不看央行的目标与约束 |
| 利差 → 汇率 → 资本流动 | 两国利差扩大，资本流向高息货币；汇率变动又反过来影响进口通胀和外资回报 | 主要央行政策分化 → 美元走强 → 新兴市场资本外流 | 汇率只看贸易差额 |
| 美元周期 | 美元是全球融资货币，美元走强会加重全球美元负债的实际负担，收紧全球金融条件 | 美元走强期，新兴市场股、债、汇同时承压 | 忽视美元债务敞口 |
| 风险溢价与情绪 | 基本面相同，情绪决定投资者要求多高的补偿；避险时风险溢价上升，价格下跌 | 地缘冲突、VIX 跳升 | 把情绪波动当成基本面恶化 |
| 杠杆与反身性 | 价格下跌 → 保证金追缴 → 被迫卖出 → 价格再跌，这部分卖压与基本面无关 | 套息交易平仓、融资盘强平、“什么都跌”（含黄金） | 把被迫卖出当成看空 |
| 久期 | 收益率上升 X 个基点，债券价格大约下跌“久期 × X 个基点”，这是数学关系 | 加息周期中长债出现较大浮亏 | 以为债券不会亏钱 |
| 实际利率与无息资产 | 黄金等无息资产的机会成本是实际利率；央行购金、避险需求和货币信用也会驱动金价 | 实际利率上行而金价仍涨，说明其他驱动力占优 | 用单一因子解释金价 |
| 期限溢价 | 长端利率 = 预期的短端利率路径 + 期限溢价；赤字扩大、通胀不确定会推高期限溢价 | 降息周期中长端利率不降反升（熊陡） | 以为央行降息长端利率一定下行 |
| 库存周期弹性 | 从被动去库转向主动补库时，需求小幅改善就能带来价格和利润的大幅弹性 | PPI 由负转正、工业利润修复 | 用需求的绝对水平判断景气 |
| 供给冲击与滞胀 | 能源、粮食的供给冲击同时推高通胀、压低增长，让央行左右为难 | 油价跳涨期股债同跌 | 把供给冲击当成需求旺盛 |
| 汇率传导 | 本币贬值后，以本币计价的进口价格上升，有时滞，也不一定完全传导 | 日元贬值 → 日本进口物价与 CPI 上行 | 以为贬值一定利好出口股 |
| 拥挤交易与均值回归 | 一致预期越强，增量买家越少，小冲击就可能引发踩踏式反转 | “最拥挤交易”反转、空头回补 | 把“大家都这么看”当作安全信号 |

## 3. 反直觉现象速查

遇到下列现象时，先按“常见解释链”找证据，**证据不支持就不写这条解释**。

| 现象 | 常见解释链 | 需要核实的证据 |
|------|-----------|---------------|
| 通胀上行，股指下跌 | 降息预期后移或加息预期升温 → 利率上行 → 估值压缩；成本推动型通胀挤压利润 | 利率期货隐含路径、10 年期收益率、PPI−CPI 剪刀差、盈利预期修正 |
| 经济数据强劲，股市下跌 | 强数据削弱宽松预期 | 数据发布当天利率与股指的同步反应 |
| 经济数据疲弱，股市上涨 | 宽松预期升温 | 同上 |
| 央行降息，长端利率反而上行 | 通胀预期或期限溢价上升、财政担忧、降息幅度不及预期 | 10Y−2Y 利差、通胀互换、国债拍卖结果 |
| 降息落地后股市下跌 | 买预期卖事实；或降息被解读为经济比想象的差 | 会前定价程度、声明措辞 |
| 避险时黄金与股票同跌 | 流动性冲击：为补保证金卖出一切可变现资产 | VIX、美元、融资余额 |
| 美元与美股同涨 | 美国增长相对更强，吸引资本流入 | 美国与其他经济体的增长差、利差 |
| 本币贬值，出口股却下跌 | 贬值伴随资本外流与风险溢价上升，盖过了出口竞争力改善 | 资本流动数据、外资持仓 |
| 油价上涨，能源股不涨 | 市场认为只是短期扰动，或担心需求破坏、暴利税 | 原油期货期限结构 |
| 盈利超预期，股价下跌 | 指引下调、预期本来就高、估值已经透支 | 一致预期、业绩指引 |

## 4. 传导的确定性分级

`analysis.impacts` 回答“哪些变化是躲不开的”。按传导机制的性质分三级：

| 等级 | 含义 | 例子 |
|------|------|------|
| **必然** | 由合约、会计规则、数学关系或已生效的制度决定，触发条件成立就一定发生；不确定的只是幅度和时点 | 收益率上行 → 存量债券市值下降；浮动利率贷款在重定价日按新利率计息；已生效的关税在报关时计入进口成本；指数调整生效日被动基金按规则调仓；本币贬值 → 外币负债折算成本币后增加；保证金跌破维持线 → 触发追缴或强平 |
| **大概率** | 历史上方向稳定，但依赖参与者行为或需要时间 | 利率上行压低高估值资产的估值；进口成本上升逐步传导到 CPI；美元走强阶段新兴市场资本外流压力上升 |
| **有条件** | 取决于另一个尚未确定的变量 | 油价上涨是否推升核心通胀，取决于持续时间和工资反应；关税是否压低进口国增长，取决于汇率吸收程度和替代来源 |

规则：

- 涉及“人会怎么做”的环节（买卖、消费、投资决策），最多标“大概率”。
- “必然”只保证方向，不保证幅度。幅度和时点写进 `horizon` 或 `mechanism`。
- “大概率”写 `condition`，说明什么情况下规律可能失效；“有条件”必须写 `condition`，用“如果……则……”。
- `horizon` 用“即时”“数周”“1–2 个季度”“更长”这类粗粒度说法。

### 常见触发与传导

| 触发 | 必然发生 | 随后大概率 |
|------|---------|-----------|
| 央行加息或降息 | 浮动利率贷款与存款按规则重定价；货币市场利率跟随 | 信贷需求、按揭负担、汇率变化 |
| 国债收益率上行 | 存量债券市值下降，持有长债的金融机构出现浮亏 | 银行资本压力、风险偏好下降 |
| 关税生效 | 进口商报关时缴纳关税，进口成本上升 | 部分转嫁到终端价格（取决于汇率与利润率）；贸易转移；抢进口之后进口回落 |
| 出口管制或制裁生效 | 受限交易必须停止或申请许可；部分结算渠道受限 | 替代供应链形成、价格分化（如原油折价） |
| 本币贬值 | 进口商品的本币价格上升；外币债务负担上升；海外收入折算后增加 | 输入型通胀、资本流动变化 |
| 油价上涨 | 炼化、航空、运输等行业燃料成本上升；产油国出口收入增加 | CPI 能源分项上行、通胀预期抬升 |
| 指数纳入或剔除 | 被动资金在生效日按权重调仓 | 生效前后价格与成交异动 |
| 资产价格大幅下跌 | 杠杆账户保证金比例下降，跌破维持线触发追缴或强平 | 连锁卖压、波动率上升 |
| 灾害导致停产 | 停产期间的产出损失和供应缺口 | 相关商品涨价、替代需求、灾后重建投资 |
| 财政赤字扩大 | 国债发行量上升 | 期限溢价上升（取决于需求承接） |

## 5. 情绪与防御策略库（含反向视角）

市场情绪变化时，机构投资者有一套相当成熟的标准动作。读懂这套动作有三层价值：

1. **解释价格**：很多价格变化并非基本面变化，而是这套动作在执行。
2. **预判资金流向**：防御动作会把钱从哪里推向哪里，事先就能知道。
3. **反向视角**：防御动作一旦拥挤，防御资产本身会变贵，风险资产可能被过度抛售。历史上，情绪极值往往出现在“大家都已经防御完”的时候。

`analysis.playbook` 每张卡片对应本期识别出的一种情绪或环境，从下表选用并按本期实际改写，不要整段照抄。

| 情绪 / 环境 | 市场惯用的防御动作 | 资金流向 | 反向视角 | 拥挤度 / 极值观察 |
|------------|-------------------|---------|---------|------------------|
| 通胀超预期、加息预期升温 | 缩短债券久期；从高估值、长久期的成长资产转向现金流近、定价权强、高股息的资产；增加通胀挂钩债券与商品敞口；提高短久期现金类资产比例 | 长债、高估值成长 → 短端现金类、价值与高股息、商品 | 通胀见顶证据出现时（PPI 环比转负、核心通胀连续放缓、工资增速回落），此前被抛售最多的长久期资产对利率下行最敏感，历史上往往最先修复；缩久期变得拥挤时，长端利率的上行空间也在收窄 | 利率期货隐含的加息或降息次数、通胀互换、基金经理调查中的“最拥挤交易” |
| 增长放缓、衰退担忧 | 转向必需消费、医疗、公用事业等需求稳定的板块；增持高等级、较长久期的国债；降低周期行业与高收益信用敞口；提高现金比例 | 周期股、高收益债、工业商品 → 防御板块、高等级国债、现金 | 衰退被充分定价时，周期资产往往先于经济数据见底，股市通常领先经济；防御板块的估值溢价扩大到历史高位时，“防御”本身就变贵了；收益率曲线由倒挂转为牛陡，常被视为周期切换的信号 | 周期与防御板块的相对强弱、高收益债利差、PMI 新订单、收益率曲线形态 |
| 流动性收紧、美元走强 | 降低杠杆；减少新兴市场与外币资产敞口或做汇率对冲；持有美元现金或短期美债 | 新兴市场、商品、高贝塔资产 → 美元现金 | 美元见顶回落时，此前流出最多的新兴市场与商品通常弹性最大；做多美元成为最拥挤交易时，反转风险随之上升 | 美元指数、新兴市场资金流、美元融资成本（如交叉货币基差）、CFTC 持仓 |
| 地缘冲突、尾部事件 | 增持黄金、美元、日元、瑞郎等传统避险资产；买入短期国债；用期权买入保护；对冲能源价格 | 风险资产 → 避险资产 | 历史上多数地缘冲击对主要股指的影响较为短暂，除非冲击改变了能源供给、全球贸易或货币政策路径；避险资产的急涨里含有事件溢价，事件缓和时溢价往往回吐 | 原油期货期限结构、金价与实际利率的偏离、VIX、避险货币走势 |
| 波动率飙升、去杠杆 | 降低整体杠杆与总敞口；提高现金；买入波动率或保护性期权；收紧风控阈值 | 一切可变现资产（包括黄金等避险资产）→ 现金 | 强制性卖盘有终点，追缴和强平完成后，与基本面无关的那部分卖压会消失；VIX 期限结构由倒挂恢复为正常升水，历史上常被视为恐慌缓解的信号；波动率有均值回归特征 | VIX 及其期限结构、MOVE、融资余额变化、Put/Call 比率 |
| 信用风险上升 | 向更高信用等级迁移；缩短信用债久期；降低单一发行人集中度；回避流动性差的资产 | 高收益债、低评级、私募信贷 → 投资级、国债 | 信用利差极度走阔时，价格里已计入高于历史平均的违约率；违约率见顶通常滞后于利差见顶 | 高收益与投资级利差、违约率、评级下调、银行贷款标准调查 |
| 情绪过热、一致看多 | 谨慎型机构做再平衡、兑现部分收益、提高持仓质量门槛、趁隐含波动率低时买入保护 | 热门主题 → 现金、低相关资产 | 这里的反向就是防御本身：一致看多时增量买家减少，对坏消息的承受力下降；但过热可以持续很久，单看情绪指标不足以判断拐点 | 散户情绪调查（如 AAII 牛熊差）、融资余额、新股发行热度、基金经理调查的现金比例 |

### 反向视角的使用边界

- **反向不等于反着做。** 有效的反向信号通常需要三件事同时出现：情绪或持仓到达极值；基本面出现边际变化（哪怕只是“不再恶化”）；价格对坏消息不再下跌。只有第一条，信号很弱。
- **极值可以维持很久。** 情绪指标可能在极端区域停留数月，判断拐点必须等待确认。
- **写法上**，反向视角描述的是“防御需求把资金推向哪里、防御拥挤时历史上意味着什么”，用“历史上往往”“通常对应”这类表述；不写“现在可以……”“是布局时机”。

## 6. 投资者笔记怎么写

`analysis.takeaways` 是报告的收尾：本期能带走哪些下次还用得上的规律或方法。

- 写 3–5 条。每条是一个可迁移的规律，不是本期新闻的复述。
- 结构：一句话规律（`title`）+ 本期例证，带 `[[id]]` 引用 + 下次怎么用（`text`）。
- 优先总结本期因果链里用到的原理，以及本期暴露出的常见误判。

> ✅ **看数据先看预期差**：本期美国 CPI 同比与上月持平，但高于预期 0.2 个百分点，当天美债收益率上行 [[us-cpi]]。市场按“意外”定价，不按“水平”定价。下次数据发布前，先记下一致预期，再看结果。

>
