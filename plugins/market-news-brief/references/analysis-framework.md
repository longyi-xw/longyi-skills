## 1. 分析的五层结构

| 层次 | 回答的问题 | 报告字段 |
|------|-----------|---------|
| 环境 | 增长、通胀、政策、流动性、外部环境分别怎样？ | `analysis.overview`、`analysis.state` |
| 状态 | 风险偏好、波动、资金流向如何？各类资产走势一致还是背离？ | `analysis.overview`、`analysis.state` |
| 周期 | 各经济体处在经济、货币、信用、库存周期的什么位置？ | `analysis.cycles` |
| 信号 | 本期新闻释放了哪些边际变化？方向、强度、反证是什么？ | `analysis.signals` |
| 情景与风险 | 接下来可能怎么演变？主要风险是什么？如何规避？ | `analysis.scenarios`、`analysis.risks`、`analysis.strategies`、`analysis.watchlist` |

分析的重点是**边际变化**：和上一期相比，什么变了。环境长期不变的部分一笔带过，篇幅留给变化。

`analysis.state` 建议的 4–6 个维度：风险偏好、流动性、波动水平、美元、通胀预期、政策预期。每个维度写一个简短的定性值（如“边际回落”），并在 `note` 里写依据。

## 2. 指标速查

| 指标 | 反映什么 | 怎么读 | 陷阱 |
|------|---------|--------|------|
| 美债 10Y−2Y / 10Y−3M 利差 | 增长与政策预期 | 倒挂通常被视为衰退预期；倒挂后重新陡峭化，要区分是短端下行（降息预期）还是长端上行（期限溢价、财政担忧） | 倒挂到衰退的时滞很长、很不稳定，不能当择时信号 |
| 实际利率（TIPS 收益率） | 真实融资成本 | 上行时，对估值敏感的资产和无息资产承压 | 黄金近年受央行购金影响，与实际利率的相关性减弱 |
| 信用利差（高收益债、投资级 OAS） | 信用风险偏好 | 走阔说明避险或违约担忧上升 | 利差处在低位时，对冲击更敏感 |
| VIX / MOVE | 股市与美债的隐含波动 | 快速上升往往伴随去杠杆 | 单日跳升可能只是事件驱动，要看持续性 |
| 美元指数 DXY | 全球美元流动性 | 美元走强通常收紧全球金融条件，新兴市场承压 | 要区分是美国强（增长驱动）还是全球弱（避险驱动） |
| 铜金比 | 增长预期与避险的相对强弱 | 上升偏向增长预期改善 | 铜受供给扰动和中国需求影响大 |
| 原油 | 通胀、地缘、需求 | 供给冲击推升通胀；需求下滑压低油价 | 区分供给侧（OPEC+、冲突）和需求侧原因 |
| 黄金 | 避险、实际利率、央行需求、货币信用 | 和美元、实际利率同涨时，往往反映避险或去美元化需求 | 多因素驱动，单独看信息量有限 |
| PMI | 景气方向 | 50 为荣枯线；新订单减产成品库存可作为领先信号 | 官方与财新/标普口径不同；季节性明显 |
| CPI / 核心 CPI / PCE | 通胀压力 | 核心与服务分项更能反映趋势 | 基数效应；能源和食品扰动 |
| 就业（非农、失业率、初请） | 劳动力市场 | 趋势比单月重要 | 修正幅度可能很大 |
| 中国社融、M1/M2 | 信用扩张与资金活化 | M1 回升通常被视为企业活跃度改善 | 口径调整（如 M1 纳入个人活期存款）会打断可比性 |
| 中国 PPI | 工业品价格与企业盈利 | 由负转正通常对应工业周期改善 | 受大宗商品输入影响 |
| 人民币汇率（含中间价） | 跨境资金与政策态度 | 中间价与市场预期的偏离反映政策意图 | 有逆周期调节因素 |
| 卢布汇率、乌拉尔油价折价 | 俄罗斯外部收入与制裁效果 | 折价扩大说明出口收入受压 | 资本管制下汇率的信号意义打折 |
| 日债收益率、日元 | 日银政策与全球套息交易 | 日元快速升值可能触发套息交易平仓 | 财务省干预会造成断点 |
| 航运运价（BDI、SCFI） | 全球贸易与供应链 | 急升常和航道受阻、供给收缩有关 | 运力变化同样会影响运价 |

## 3. 周期定位

### 经济周期（增长 × 通胀）

| 增长方向 | 通胀方向 | 阶段描述 |
|---------|---------|---------|
| 上行 | 下行或低位 | 复苏 |
| 上行 | 上行 | 扩张或过热 |
| 下行 | 上行 | 滞胀 |
| 下行 | 下行 | 放缓或衰退 |

这是描述性框架，用来给“环境”定性，**不要机械地套出资产配置结论**，那就成了投资建议。增长和通胀方向看趋势（3–6 个月），不看单月。证据不一致时，写“分化”“过渡阶段”或“证据不足”，并降低置信度。

### 货币政策周期

紧缩（加息、缩表）→ 观望（暂停）→ 宽松（降息、扩表）。判断依据：最近一次决议、前瞻指引的措辞变化、利率期货隐含的路径（引用来源）、官员讲话的分歧程度。

### 信用周期

信贷增速、信用利差、违约率、银行贷款标准调查（美国 SLOOS、欧元区 BLS）。信用扩张早于经济回升，收缩早于经济放缓。

### 库存周期（主要用于中国和美国制造业）

| 需求 | 库存 | 阶段 |
|------|------|------|
| 上升 | 下降 | 被动去库 |
| 上升 | 上升 | 主动补库 |
| 下降 | 上升 | 被动补库 |
| 下降 | 下降 | 主动去库 |

需求可以看 PMI 新订单、营收增速，库存看产成品库存指数、工业企业存货同比。

### 周期表的写法

`analysis.cycles` 每个经济体一行：增长、通胀、货币政策、财政政策用简短定性词，`phase` 写综合判断，`evidence` 写 1–2 条关键依据并引用条目，`confidence` 写置信度。本期没有新数据的经济体，可沿用上期判断，并在依据里写明“本期无新增数据”。

## 4. 各经济体的分析要点

- **美国**：就业与通胀的组合决定美联储节奏；财政赤字与国债供给影响长端利率；关税政策影响通胀预期和全球贸易；美元与美债是全球金融条件的锚。
- **中国**：政策取向（货币、财政、地产、资本市场）是核心变量；关注内需（消费、地产）与外需（出口）的分化、价格水平（CPI、PPI）是否走出低位、信用是否扩张；重要会议的定调措辞变化本身就是信号。
- **俄罗斯**：高利率与通胀的拉锯；能源出口收入（油价、折价、出口量）决定财政和卢布；制裁与反制裁的变化；数据披露受限，结论的置信度相应调低。
- **欧元区**：ECB 节奏与核心国财政规则；德国制造业与能源成本；成员国利差反映财政风险。
- **日本**：日银政策正常化节奏；日元与全球套息交易的联动；工资与通胀的循环是否形成。
- **跨经济体**：主要央行的政策分化（利差 → 汇率 → 资本流动）；贸易与制裁的连锁反应；大宗商品作为传导链条。

## 5. 信号提取方法

### 四类信号

| 类型 | 来源 | 提取方法 |
|------|------|---------|
| 政策信号 | 央行声明、会议通稿、官员讲话、政策文件 | **措辞比对**：与上一次同类文件逐句对比，增删了哪些表述（如“适度宽松”“必要时”“耐心”），措辞变化往往早于行动 |
| 数据信号 | 经济数据发布 | **预期差**：实际值与市场一致预期的差距（引用调查来源）；**趋势转折**：连续几个月方向是否改变；**分项结构**：总量和分项是否一致 |
| 价格信号 | 股债汇商品的走势 | **跨资产一致性**：股涨债跌（增长乐观）、股跌债涨（避险）、股债双杀（通胀或流动性冲击）、美元与黄金同涨（避险需求）等 |
| 事件信号 | 地缘、灾害、制裁、选举 | **传导链**：事件 → 受影响的商品或行业 → 价格 → 通胀或增长 → 政策，逐环写清，并标明哪些环节已被观察到、哪些是推测 |

### 信号卡片的写法

`analysis.signals` 每张卡片：

- `observation`：观察到的事实（引用条目）
- `interpretation`：可能的含义，用“可能”“指向”等有分寸的表述
- `counterEvidence`：反向证据，没有就写“暂未发现明显反向证据”
- `direction`：对整体风险偏好的方向，`risk-on`（上升）/ `risk-off`（避险）/ `mixed`（分化）/ `neutral`（中性）。描述的是市场情绪的方向，不是买卖建议
- `strength`：1–3，按影响范围和持续性判断
- `confidence`：高 / 中 / 低

一期报告选 3–8 个最重要的信号，宁缺毋滥。

## 6. 情景构建

1. 先确定本期最大的 1–2 个不确定性，例如“美联储下次会议的节奏”“某地缘冲突是否升级”。
2. 围绕不确定性写三个情景：基准（延续当前趋势）、上行（风险缓解或超预期改善）、下行（风险兑现）。
3. 每个情景写清**触发条件**（什么事发生会进入这个情景）和**观察指标**（看什么数据和事件来确认）。
4. 可能性只用定性词。基准情景不一定是可能性最高的，按证据判断。
5. 观察指标要和 `watchlist` 的日程对应起来，方便读者跟踪。

## 7. 风险规避思路库

只在本期环境确实出现对应特征时选用，并按实际情况改写，不要整段照抄。

| 环境特征 | 风险管理思路 |
|---------|-------------|
| 波动率上升、重大事件密集 | 关注整体杠杆和单一资产集中度；预留流动性应对跳空；留意事件前后买卖价差扩大带来的成本 |
| 利率方向不确定、政策预期反复 | 了解所持资产对利率变化的敏感度（久期）；避免把单次表态当作政策定论 |
| 汇率波动加大 | 梳理外币资产和负债的汇率敞口；了解对冲方式及其成本 |
| 信用利差走阔、违约事件增加 | 关注信用资质与发行人集中度；留意流动性较差的资产在压力下的变现难度 |
| 地缘冲突、制裁范围变化 | 关注合规与跨境支付结算风险；评估对单一地区和供应链的依赖程度 |
| 大宗商品价格剧烈波动 | 识别成本端或收入端对相关商品的敞口；区分短期扰动和趋势变化 |
| 自然灾害影响生产 | 关注区域和行业集中度；了解保险保障与供应链替代安排 |
| 市场情绪一致性过高 | 留意拥挤交易反转的风险；核实消息来源，不追逐单一消息 |
| 数据缺失、信息不透明 | 对相关判断保持低置信度；等待更多数据确认后再形成结论 |

通用原则：分散化、保持流动性、事先定好自己的风险承受边界、定期再平衡、核实信息来源。这些原则不随市场环境改变，正文提一句即可，不必展开。

## 8. 常见误区

- **用单一数据下周期结论**：一个月的数据不构成趋势。
- **后视镜叙事**：先看到涨跌，再找一个新闻解释它。没有来源支持的因果不要写。
- **只写支持性证据**：每个判断都要写反向证据。
- **把相关当因果**：“同期”不等于“导致”。
- **混淆预期与现实**：市场已经定价的事件，落地时价格反应可能很小，甚至相反。
- **把描述写成建议**：“环境对 A 类资产不利”是描述，“应减持 A 类资产”是建议，后者不写。
- **用旧知识补数据**：检索不到的数据就写“未获取”，不要凭记忆补。
